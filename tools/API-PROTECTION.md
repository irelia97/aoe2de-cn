# 高成本 API 访问保护

`server/services/api-protection.js` 在请求进入业务处理前检查访问来源、频率和并发。

- 录像分析、录像元数据、录像下载、玩家历史/资料/关联账号/天梯信息及头像资料接口拒绝带爬虫、自动化客户端标识的请求。User-Agent 可以伪装，因此另外实施限流。
- 跨站请求不可调用受保护接口。录像分析和元数据查询由前端附带 `X-AOE2-Client: web`；录像下载导航须有本站来源页面。这是轻量请求校验，不是身份认证。
- 录像分析和下载共用每 IP 2 次/分钟、10 次/小时；元数据 30 次/分钟、120 次/小时；玩家接口共用 120 次/分钟、600 次/小时。超限返回 429 和 `Retry-After`，错误提示包含额度及等待秒数。
- 每个 IP 同时最多一个录像分析/下载任务，公开录像分析全站最多一个，公开高成本录像任务最多两个，为自动摘要保留一个录像分析槽位。客户端断线后，正在运行的处理仍占用槽位，直到处理结束。
- 服务器内部调用绕过访问层保护，自动摘要仍直接使用录像分析服务。客户端 IP 复用现有代理识别，只信任内部代理提供的 `X-Real-IP`；Nginx 必须覆盖该头，不能直接信任访客提供的头。
- `public/robots.txt` 禁止抓取 API 和带查询参数的录像分析页；API 和录像分析详情页响应携带 `X-Robots-Tag: noindex, nofollow`。robots 是对守规爬虫的提示，不是安全边界。
- 限流状态会持久保存，IP 使用 SHA-256 摘要，最多保留 10000 个 IP/类别条目。配额保存至 `.cache/api-limits.json`，网站重启时恢复；后台上游和任务由独立服务运行。

仅本机可访问统计：`curl http://127.0.0.1:3000/api/protection/status`，包含各拦截原因计数及当前并发，不包含 IP 或会话信息。录像任务轮询使用独立额度，不扣除任务提交额度。前端发布版本为 `reliability-v137`，旧页面若遇到 403 应刷新。

测试：`node --test tools/test-api-protection.mjs`。线上验证使用无效录像 ID，确保不会下载真实录像或发送任何弹幕。

当前进程、上游调度、备份和健康检查详见 `tools/RELIABILITY.md`。
